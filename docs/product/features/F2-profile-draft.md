# F2. 사용자 프로필·개인화와 답장 초안

> 상태: 초안 | 담당: D | 최종 수정: 2026-10-16
> 설계안: 화면·구조 설계안 v0.2 — 7쪽(프로필·문체 설정), 8쪽(개인화된 답장 초안)
> 화면 정의서: `docs/design/screens/` S06 · S09 (목업: `docs/design/screens/mockups/png/`)

## 1. 목적

답장 초안과 주간 보고가 **'내가 쓴 것처럼'** 나오도록 필요한 정보를 한곳에서 정한다. 사용자가 직접 입력한 값과, Klover에서 보낸 메일에서 학습한 문체를 함께 쓴다.

이 프로필로 두 가지 기능이 동작한다.

- **답장 초안**: 원본·관련 메일(F1) + 문체·부서·서명(F2) → 초안
- **주간 보고(F4)**: 보고 양식·문체를 F2에서 가져옴

## 2. 프로필 설정 화면 (설정 > 내 프로필·문체)

| 영역 | 항목 | 예시 |
| --- | --- | --- |
| ① 기본 정보 | 이름, 직급, 소속, 담당 업무, 자주 연락하는 부서·회사(태그) | 홍길동 / 과장 / 경영지원본부 재무팀 / 부서별 예산 편성·집행 관리, 월·분기 결산, 외부 감사 대응 / 영업기획팀, 전략기획팀, 한빛회계법인 |

## 3. 답장 초안 생성 시나리오

1. 메일 읽기 화면에서 [답장 초안 만들기]를 누른다.
2. 답장 창이 열린다. 왼쪽에 원본 메일과 **◆ 요청사항**(① 3분기 집행 현황 엑셀 ② 마케팅비·출장비 월별 구분 ③ 마감 10/16(금)), 오른쪽에 초안.
3. 상단 **답장 방향** 칩: AI가 2~3개 제안 (예: 기한 내 송부 약속 / 기한 조정 요청 / 추가 정보 문의). 기본 선택은 첫 번째. 바꾸면 초안 다시 생성.
4. 초안 본문에서 **프로필이 반영된 부분에 밑줄** 표시 (인사, 마무리, 서명, 자주 쓰는 표현, 참고 메일 인용)
5. 하단 **"이 초안에 반영된 것"**: 프로필 항목 + 참고한 과거 메일 목록(Vector DB 검색 결과)
6. 빠른 수정 버튼: [더 짧게] [더 정중하게] [다시 쓰기]
7. 사용자가 직접 고친 뒤 [보내기]. **발송은 항상 사용자가 직접 누른다.** [임시 저장] 가능.

## 4. 초안이 만들어지는 과정

```
원본 메일·요청사항 (F1) ┐
관련 과거 메일 (Vector DB) ├─▶ 프롬프트 구성(답장 방향 반영) ─▶ LLM ─▶ 초안 + 근거 표시 ─▶ 사용자 수정 후 직접 발송
프로필·문체 (F2)        ┘
```

- 관련 과거 메일: 같은 스레드 + 같은 상대와 주고받은 메일 + 의미가 비슷한 메일 상위 3건
- LLM 출력: 본문 + 반영 근거(어느 문장이 어느 프로필 항목/참고 메일에서 왔는지)

## 5. 문체 학습 규칙

- 대상: 첫 실행 때 동의한 경우, **Klover에서 보낸 메일만**
- 추출: 자주 쓰는 표현(상위 10개), 인사·마무리 패턴, 문장 특징(결론 먼저, 날짜 형식, 목록 사용 여부)
- 갱신: 보낸 메일 10건마다 재분석 (데모 기준)
- 사용자가 표현을 눌러 제외하면 이후 초안에 쓰지 않음
- 설정 > 개인정보·학습 데이터에서 학습 끄기·기록 삭제 가능

## 6. 데이터·API

- `GET /profile` / `PUT /profile`
- `GET /profile/style` — 학습 결과 / `DELETE /profile/style` — 학습 기록 삭제
- `POST /profile/preview` — 설정값으로 예시 답장 생성
- `POST /drafts` 입력: `{ mail_id, direction? }` 출력: `{ directions[], body, evidence[] }`
- `POST /drafts/{draft_id}/revise` 입력: `{ action: "shorter" | "politer" | "rewrite" }`
- 프롬프트: `apps/server/app/ai/prompts/draft.md`, `style_extract.md`

## 7. 수용 기준

- [ ] 프로필을 저장하면 다음 초안부터 인사·마무리·서명이 그대로 들어간다
- [ ] 격식 수준·길이를 바꾸면 미리보기가 3초 안에 바뀐다
- [ ] [답장 초안 만들기] 후 10초 안에 초안과 답장 방향 칩 2~3개가 나온다
- [ ] 초안의 프로필 반영 부분에 밑줄이 있고, "이 초안에 반영된 것"에 근거가 나온다
- [ ] 참고한 과거 메일이 있으면 제목과 날짜가 표시된다 (없으면 표시하지 않음)
- [ ] [더 짧게] [더 정중하게] [다시 쓰기]가 동작한다
- [ ] 초안은 자동으로 발송되지 않는다
- [ ] 문체 학습을 끄면 학습 결과를 쓰지 않고, 기록 삭제 시 학습 결과가 지워진다

## 8. 이번 범위 아님

- 받은 메일 없이 새 메일을 AI로 작성하기
- 첨부파일 자동 첨부
- 여러 언어(영문) 답장

## 9. 결정 사항 / 남은 확인 포인트

**결정 사항**

- 문체 학습은 첫 실행 때 동의를 받고 켬
- 주간 보고 양식은 개인이 직접 설정
- 발송은 항상 사용자가 직접

**남은 확인 포인트**

- 초안을 별도 패널로 보여 줄지, 작성 창에 바로 채울지
- 사용자가 고친 초안을 다시 문체 학습에 반영할지
- 답장 초안이 독립 기능인지, 기능 2의 일부인지
