# F3. 자연어 검색

> 상태: 초안 | 담당: D | 최종 수정: 2026-10-16
> 설계안: 화면·구조 설계안 v0.2 — 9쪽(처리 과정), 10쪽(검색 화면)
> 화면 정의서: `docs/design/screens/` S07 (목업: `docs/design/screens/mockups/png/`)

## 1. 목적

검색창에 말하듯 입력하면, AI가 어떻게 이해했는지 먼저 보여 주고 그 조건으로 찾은 메일과 요약 답변을 함께 보여 준다.

핵심 아이디어: 문장을 **'정확히 걸러야 하는 조건'** 과 **'의미로 찾아야 하는 주제'** 로 나눈다. 조건으로 범위를 좁히고, 그 안에서 의미가 가까운 순으로 보여 준다.

## 2. 사용자 시나리오

1. 받은편지함 상단 검색창(◆ "무엇이든 물어보세요")에 입력: "지난달 영업기획팀이랑 주고받은 예산 관련 메일 중에 아직 답 안 한 거 찾아줘" → Enter
2. 검색 화면이 열리고 **"이렇게 이해했어요"** 칩이 보인다: `기간 2026년 9월 ×` `상대 영업기획팀 ×` `주제 예산 ×` `상태 내가 회신 안 함 ×` `+ 조건 추가`
3. **◆ AI 답변**: "지난달(9월) 영업기획팀과 주고받은 예산 관련 메일 중 아직 회신하지 않은 메일은 3건입니다. 가장 오래된 것은 박지훈 과장의 '판촉비 예산 전용 가능 여부'로 35일째 답이 없습니다 [3]. …" — 문장마다 출처 번호
4. **조건에 맞는 메일 3건** (관련도순): 번호, 발신자, 날짜, 제목, 일치 부분 인용(하이라이트), 태그(카테고리, 미회신 N일), 맞는 이유("'예산 재배정'이 주제와 일치"), [답장 초안] 버튼
5. **조건을 일부만 만족하는 메일 N건** (접어서 표시, "1건 더 보기")
6. 칩의 ×를 누르면 그 조건을 빼고 즉시 다시 검색

## 3. 처리 과정

| 단계 | 하는 일 | 예시 |
| --- | --- | --- |
| 1. 질의 해석 (LLM) | 문장을 구조화 조건과 의미 질의로 분리 | — |
| 2-a. 구조화 조건 | 기간, 상대, 상태, 대상(받은/보낸) | 2026-09-01 ~ 09-30 / 영업기획팀 소속 발신·수신자 / 회신 필요=예, 내가 회신 안 함 / 받은 메일+보낸 메일 |
| 2-b. 의미 질의 | 주제, 확장어, 임베딩 변환 | 예산 / 예산 집행, 예산 편성, 비용 재배정, 전용 |
| 3. 세 가지 검색 | 메타데이터 필터 / 키워드 검색 / 벡터 검색 (벡터 검색에도 같은 조건 적용) | 후보 38건 |
| 4. 결과 합치기·재정렬 | 조건을 모두 만족 + 의미 관련도 높은 순 | 최종 3건 |
| 5. 출력 | 결과 목록(맞는 이유) + AI 답변 요약(출처 번호) | — |

세 가지 검색을 함께 쓰는 이유:

- **메타데이터 필터**: 기간, 사람, 회신 여부처럼 틀리면 안 되는 조건
- **키워드 검색**: 문서 번호, 고유명사처럼 글자 그대로 찾아야 하는 것
- **벡터 검색**: '예산'을 물으면 '비용 재배정' 메일도 찾는 의미 검색

상대 이름 해석: "영업기획팀" → 메타데이터의 `from`/`to` 조직 정보와 F2의 '자주 연락하는 부서'를 참고해 사람 목록으로 바꾼다.

## 4. 화면 구성

- 상단: 검색 입력창 + "이렇게 이해했어요" 칩 줄
- 가운데: AI 답변 → 조건에 맞는 메일 → 일부 만족 메일
- 오른쪽 **필터 패널**: 기간(직접 수정), 카테고리, 첨부파일(전체/있음), 최근 검색
- 맨 아래: "◆ 이어서 질문하기… 예: 이 중에 제일 급한 거 답장 써줘" — **2차 기능, 데모에서는 비활성 표시만**

## 5. 데이터·API

- `POST /search` 입력: `{ query, overrides? }` 출력: `{ parsed: {filters, topic, expansions}, results: [{mail_id, score, reason, snippet}], partial: [...], answer: {text, citations[]} }`
- `overrides`: 사용자가 칩을 지우거나 필터 패널에서 바꾼 조건
- `GET /search/recent` — 최근 검색
- 서비스: `apps/server/app/services/search.py`, 프롬프트: `ai/prompts/search_parse.md`, `search_answer.md`

## 6. 수용 기준

- [ ] "지난달"·"이번 주"·"어제" 같은 표현을 오늘 날짜 기준 날짜 범위로 바꾼다
- [ ] 해석 결과가 칩으로 보이고, 칩을 지우면 그 조건 없이 다시 검색된다
- [ ] fixture 시나리오의 예시 질문에 정답 메일 3건이 모두 결과에 포함된다
- [ ] AI 답변 문장마다 출처 번호가 있고, 번호를 누르면 해당 메일로 이동한다
- [ ] AI 답변은 검색된 메일 내용만 근거로 한다 (결과 0건이면 "찾은 메일이 없습니다")
- [ ] 결과 메일마다 조건에 맞는 이유 한 줄이 보인다
- [ ] 검색 결과의 [답장 초안]이 F2 답장 창을 연다
- [ ] 첫 결과가 5초 안에 나온다 (데모 기준)

## 7. 이번 범위 아님 (2차)

- 이어서 질문하기(대화형 검색)
- 첨부파일 내용 검색

## 8. 결정 사항 / 남은 확인 포인트

**결정 사항**

- 결과 목록 + AI 답변 요약은 1차
- 이어서 질문하는 대화형 검색은 2차

**남은 확인 포인트**

- 검색 화면을 별도 탭으로 둘지, 받은편지함 위에 겹쳐 띄울지
- 답장 초안까지 검색 화면에서 바로 이어지게 할지
- 검색에도 프로필(담당 업무)을 반영해 중요도를 조정할지
