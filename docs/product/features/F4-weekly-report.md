# F4. 주간 보고 만들기

> 상태: 초안 | 담당: D (화면은 A와 분담 가능) | 최종 수정: 2026-10-16
> 설계안: 화면·구조 설계안 v0.2 — 11쪽(주간 보고 생성 화면)
> 화면 정의서: `docs/design/screens/` S08 (목업: `docs/design/screens/mockups/png/`)

## 1. 목적

기간만 고르면 그 주에 주고받은 메일을 업무 단위로 묶어, 프로필에 정한 양식과 문체로 주간 업무 보고서를 만들어 준다. **모든 항목은 근거 메일로 연결**되어 사용자가 원문을 확인할 수 있다.

## 2. 사용자 시나리오

1. 사이드바 '도구 > 주간 보고'를 연다.
2. 상단에서 선택 (기본값은 F2 프로필 설정):
   - 기간: "10월 2주차 (10/5 ~ 10/9) ▾"
   - 양식: "내 양식 (개조식) ▾"
   - 보고 대상: "이수진 팀장"
3. 보고서가 만들어진다.

```
재무팀 주간 업무 보고 (10/5 ~ 10/9)
홍길동 과장 | 작성 10/12(월) | 한글날(10/9) 휴무 반영

1. 금주 주요 업무
 - 3분기 결산 1차 마감 완료 (10/7), 부서별 예산 집행률 92.4% 집계      [근거 4]
 - 9월 법인카드 정산 완료, 증빙 누락 6건 해당 부서에 보완 요청          [근거 3]
2. 진행 중인 업무
 - 4분기 예산 재배정: 영업기획팀 요청분 검토 중, 10/16 집행 현황 자료 송부 예정 [근거 2]
 - 한빛회계법인 중간감사 현장 일정 협의 중 (10/27~29 후보)              [근거 2]
3. 이슈·요청사항
 - 해외 출장비 예산 초과분(약 1,200만 원) 처리 기준 결정 필요 → 팀장님 검토 요청 [근거 3]
4. 차주 계획
 - 10/16 3분기 결산 리뷰 회의 참석 및 자료 준비                         [근거 1]
 - 4분기 사업계획 초안 재무 검토 의견 회신 (10/20 마감)                 [근거 1]
```

4. 항목의 [근거 N]을 누르면 오른쪽 패널에 **선택한 항목의 근거 메일** 목록(제목, 보낸 사람 → 받는 사람, 날짜)이 보인다.
5. 오른쪽 아래 **포함 범위**: 기간 내 메일 86건 / 업무로 묶인 메일 41건(7개 업무) / 제외(뉴스레터·공지 등) 45건 / [제외된 메일 보기]
6. 보고서 본문은 바로 편집할 수 있다.
7. 하단 버튼: [복사] [Word로 내보내기] [이수진 팀장에게 메일로 보내기] / 상단 [다시 만들기]

## 3. 보고서가 만들어지는 과정

| 단계 | 하는 일 | 사용 데이터 |
| --- | --- | --- |
| 1. 기간으로 메일 필터 | 기간 내 받은·보낸 메일, 뉴스레터·광고·공지 제외 | 메타데이터 DB |
| 2. 업무 단위로 묶기 | 스레드·프로젝트(`entities`)별로 그룹화 | F1 메타데이터 |
| 3. 상태 판단 | 업무마다 완료 / 진행 / 이슈 / 차주 예정 판단 | LLM |
| 4. 작성 | 프로필 양식(섹션 순서·개조식/서술형)과 문체로 작성 | F2 프로필, LLM |
| 5. 근거 연결 | 항목마다 근거 메일 `mail_id` 연결 | — |

- 공휴일 반영: 기간 안의 공휴일을 부제에 표시 (데모: 한국 공휴일 목록 고정 파일)
- '차주 계획'은 다음 주 날짜가 언급된 메일·일정 제안(F5)에서 가져온다.

## 4. 데이터·API

- `POST /reports/weekly` 입력: `{ start, end, template?, recipient? }` 출력: `{ title, subtitle, sections: [{name, items: [{text, evidence: [mail_id]}]}], scope: {total, grouped, groups, excluded} }`
- `GET /reports/weekly/{report_id}/excluded` — 제외된 메일 목록
- `POST /reports/weekly/{report_id}/export?format=docx`
- `POST /reports/weekly/{report_id}/send` — 보고 대상에게 메일 작성 창 열기(발송은 사용자가 직접)
- 서비스: `apps/server/app/services/report.py`, 프롬프트: `ai/prompts/weekly_report.md`

## 5. 수용 기준

- [ ] 기간·양식·보고 대상 기본값이 프로필 설정과 같다
- [ ] 섹션 순서와 개조식/서술형이 프로필 설정대로 나온다
- [ ] 모든 항목에 근거 메일이 1건 이상 연결되고, 누르면 오른쪽에 목록이 보인다
- [ ] 근거 없는 항목을 만들지 않는다 (메일에 없는 내용 금지)
- [ ] 포함 범위 숫자(전체 = 묶인 + 제외)가 맞고, 제외된 메일을 볼 수 있다
- [ ] 본문을 편집한 뒤 복사·Word 내보내기에 편집 내용이 반영된다
- [ ] '메일로 보내기'는 작성 창을 채워서 열 뿐, 자동 발송하지 않는다
- [ ] fixture 1주치 메일로 30초 안에 보고서가 만들어진다

## 6. 이번 범위 아님

- 매주 정해진 요일 자동 생성
- 캘린더 일정 등 메일 외 정보 포함
- 팀 단위 보고 취합

## 7. 결정 사항 / 남은 확인 포인트

**결정 사항**

- 보고 양식은 개인이 설정 (프로필의 섹션·대상·표현)
- 사용 1주 후부터 사용 가능 (F0 기능 준비 상태에 표시)

**남은 확인 포인트**

- 매주 정해진 요일에 자동으로 만들어 둘지
- 메일 외 정보(캘린더 일정 등)도 보고에 넣을지
