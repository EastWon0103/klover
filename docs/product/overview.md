# Klover 서비스 개요

> 최종 수정: 2026-10-16

## 이름

**Klover** — 클로버(Clover)의 C를 Koscom의 K로 바꾼 이름. 설계안의 "AI 메일(가칭)"은 모두 Klover로 바꿔 부른다.

## 한 줄 소개

받은 메일을 AI가 바로 읽고 분류·요약·제안까지 해 주는, Gmail을 대체하는 Windows 데스크톱 메일 앱.

## 구성

| 항목 | 내용 |
| --- | --- |
| 구성 | 데스크톱 앱 + 서버 |
| 데스크톱 | Windows 10 이상 |
| 앱 역할 | Gmail을 대체하는 메일 앱, 과거 메일 없이 시작 |
| 단계 | 데모로 시작 |
| 예시 사용자 | 홍길동 과장, 경영지원본부 재무팀 |

## 메일 소스 확장 단계

1. **1단계: Gmail (상용)** — Gmail API ← 현재
2. 2단계: 사외 웹메일 — IMAP / SMTP
3. 3단계: 사내 메일 — Exchange, 그룹웨어 API (LLM·임베딩도 사내 모델로 전환)

## 기능 목록

| 번호 | 기능 | 정의서 | 담당 |
| --- | --- | --- | --- |
| F0 | 첫 실행 설정과 기본 메일함 | [F0-onboarding-mailbox.md](features/F0-onboarding-mailbox.md) | A |
| F1 | 메일 분류 및 Vector DB 저장 | [F1-mail-analysis.md](features/F1-mail-analysis.md) | C |

> 기능 정의서 원본에는 '기능 3'이 두 번 적혀 있어, 설계안 v0.2 기준으로 자연어 검색 = F3, 주간 보고 = F4, AI 스캔 = F5로 정리했다. F0는 설계안 4·6쪽의 첫 실행·기본 메일 기능을 따로 뺀 것이다.

## 기능 간 연결 (세 개의 층)

| 층 | 기능 | 설명 |
| --- | --- | --- |
| 사용자 기능 | 답장 초안(F2), 주간 보고(F4), 자연어 검색(F3), AI 스캔 제안(F5) | 사용자가 직접 쓰는 기능 |
| 개인화 기반 | F2 사용자 프로필·개인화 | 부서·직급·담당 업무, 문체·서명, 보고 양식 |
| 데이터 기반 | F1 메일 분류 및 저장 | 메타데이터 DB + Vector DB |
| 입력 | 메일 수신 | 앱 사용 시작 이후 도착한 메일부터 |

- 답장 초안 = 원본·관련 메일(F1) + 문체·부서·서명(F2)
- 주간 보고 = 기간 내 메일(F1) + 보고 양식·문체(F2)
- 자연어 검색 = 메타데이터 필터 + 벡터 검색(F1)
- AI 스캔 = 수신 즉시 나온 분석 결과(F1)를 바로 제안으로 전환
- 검색·AI 스캔은 프로필 없이도 동작 (반영 여부는 확인 포인트)

## 원칙

- **제안만 하고 실행은 사용자가** — 발송, 캘린더 등록은 항상 사용자 승인
- **근거를 보여 준다** — 요약·답변·보고 항목마다 출처 메일 연결
- **교체 가능한 구조** — 메일 소스(커넥터), 모델(LLM·임베딩), 저장소를 분리해 3단계 사내 구축으로 옮길 수 있게
