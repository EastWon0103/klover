# S02. 빈 받은편지함

> 기능 F0 · 담당 A · 라우트 `/mail/inbox` (메일 0건일 때) · 목업 [S02-inbox-empty.png](mockups/png/S02-inbox-empty.png)

## 1. 목적

과거 메일 없이 시작한다는 점을 알리고, 지금 바로 쓸 수 있는 기능과 시간이 지나야 쓸 수 있는 기능을 보여 준다.

## 2. 진입 · 나가기

- 진입: S01 완료 직후, 또는 받은편지함에 메일이 0건일 때.
- 나가기: 첫 메일이 도착하면 자동으로 S03 모양으로 바뀐다(WebSocket `mail.received`).

## 3. 레이아웃

공통 틀(상단 바 + 사이드바). 메일 목록과 읽기 영역 대신 **본문 전체에 빈 상태** 하나를 가운데 배치(폭 560).
사이드바 건수와 알림 배지는 표시하지 않는다.

## 4. 구성 요소

| # | 요소 | 컴포넌트 | 내용 |
| --- | --- | --- | --- |
| 1 | 빈 상태 | `EmptyState` | 112×112 둥근 사각(`clover-50`, 모서리 28) 안 로고 마크 64 → 제목(heading) → 설명 2줄(15px muted) |
| 2 | 행동 버튼 | `Button` primary · secondary | [새 메일 쓰기] → S05 · [프로필 확인] → S09 |
| 3 | 기능 준비 상태 | `ReadinessList` | 5줄, 줄 높이 40, 사이 1px 선. 오른쪽 상태: ● 초록 "바로 사용" / ○ 회색 "메일이 쌓이는 대로" 등 |

## 5. 동작

- 상태 문구는 서버 값으로 갱신: 주간 보고는 사용 시작 7일 뒤 "바로 사용", 문체 학습은 보낸 메일 수 표시("· 3건").
- 검색창은 쓸 수 있지만 결과가 없으면 S07의 빈 결과 화면을 보여 준다.

## 6. 상태

- 불러오는 중: 빈 상태 대신 목록 스켈레톤(S03 모양)을 잠깐 보여 준 뒤 0건이면 S02.

## 7. 문구

- 제목: "받은편지함이 비어 있습니다"
- 설명: "지금부터 도착하는 메일을 AI가 분석합니다." / "이전 메일은 가져오지 않습니다. (Gmail에 있는 기존 메일은 Gmail에서 확인하세요)"
- 준비 상태: AI 분류 · AI 스캔 알림 — 바로 사용 / 답장 초안 — 바로 사용 (문체 설정 기준) / 자연어 검색 — 메일이 쌓이는 대로 / 주간 보고 — 사용 1주 후부터 / 문체 학습 — 보낸 메일이 쌓이는 대로 · N건

## 8. 데이터 · API

`GET /mails?box=inbox` (0건) · `GET /status/readiness` (신규 제안: 사용 시작일, 보낸 메일 수) — `docs/architecture/api.md`에 추가 필요
