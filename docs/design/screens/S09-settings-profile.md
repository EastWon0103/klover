# S09. 설정 · 내 프로필·문체 (F2)

> 기능 F2 · 담당 D · 라우트 `/settings/profile` · 목업 [S09-settings-profile.png](mockups/png/S09-settings-profile.png)

## 1. 목적

답장 초안과 주간 보고가 '내가 쓴 것처럼' 나오도록 기본 정보·문체·학습 결과·보고 양식을 한 화면에서 정하고, 바꾼 결과를 미리 본다.

## 2. 진입 · 나가기

- 진입: 사이드바 '설정', S02 [프로필 확인], 상단 아바타 메뉴 '내 프로필'.
- 나가기: 왼쪽 위 [‹ 받은편지함]. 저장하지 않은 변경이 있으면 확인 대화상자.

## 3. 레이아웃

상단 바는 유지, **사이드바 자리에 설정 메뉴 220**(같은 모양). 본문은 2열 카드 그리드(간격 12, 패딩 16·24) + 하단 버튼 줄.

| 줄 | 왼쪽 | 오른쪽 |
| --- | --- | --- |
| 1 | ① 기본 정보 | ② 문체 |
| 2 | ③ 보낸 메일에서 내 문체 학습 (2열 차지) | |
| 3 | ④ 주간 보고 양식 | ⑤ 미리보기 |

설정 메뉴: 내 프로필·문체 / 주간 보고 / 메일 계정 연결 / 캘린더 연결 / 알림·시작 프로그램 / 개인정보·학습 데이터. (이 화면 외 설정은 같은 틀에 카드만 다르게 — 알림 설정은 S01 4단계 카드를 그대로 재사용)

## 4. 구성 요소

| # | 요소 | 컴포넌트 | 내용 |
| --- | --- | --- | --- |
| 1 | 기본 정보 | `Input` ×4 + 태그 입력 | 이름·직급(2열) / 소속 / 담당 업무 / 자주 연락하는 부서·회사(회색 알약 태그 + "+ 추가" 점선) |
| 2 | 문체 | `Slider` · `Segmented` · `Input` ×2 · `Textarea` | 격식 수준(편하게 ↔ 정중하게) / 답장 길이(짧게·보통·자세히) / 첫 인사·마무리(2열) / 서명 |
| 3 | 문체 학습 | `Switch` + 표현 칩 | 머리 "◆ 보낸 메일에서 내 문체 학습" + "사용 시작 후 보낸 메일 N건 분석" + 스위치. 자주 쓰는 표현 칩(흰 바탕, ai-border, ×로 제외) / 문장 특징 한 줄 |
| 4 | 주간 보고 양식 | 끌어서 순서 바꾸는 목록(2×2) + `Input` + `Segmented` | 섹션 4개(⋮⋮ 손잡이) / 보고 대상 / 표현(개조식·서술형) |
| 5 | 미리보기 | 회색 박스 | 현재 설정으로 쓴 답장 예시 4줄. 설정을 바꾸면 1초 뒤 갱신 |

## 5. 동작

- 값 변경 → 하단 [저장] 활성, 미리보기는 저장 전에도 바뀐다(`POST /profile/preview`, 입력 멈춘 뒤 1초).
- 표현 칩 × → 칩이 흐려지며 "제외됨 · 되돌리기".
- 문체 학습 스위치 끔 → 확인 "학습 결과를 쓰지 않아요. 기록은 '개인정보·학습 데이터'에서 지울 수 있어요."
- [저장] → `PUT /profile` → 토스트 "저장했어요. 다음 초안부터 반영돼요."

## 6. 상태

- 학습한 메일 0건: 표현 칩 자리에 caption "보낸 메일이 쌓이면 자주 쓰는 표현이 여기에 나타나요"
- 미리보기 생성 중: 박스 안 스켈레톤 4줄

## 7. 문구

- 학습 안내: "과거 메일 없이 시작하므로, 초기에는 위 문체 설정을 쓰고 보낸 메일이 쌓일수록 학습 결과를 더 반영합니다."

## 8. 데이터 · API

`GET/PUT /profile` · `GET /profile/style` · `POST /profile/preview` · 필드는 `data-model.md`의 `profiles`

- [ ] 설정을 바꾸면 미리보기가 바뀐다
