# S05. 새 메일 작성 · 답장

> 기능 F0 · 담당 A · 라우트 `/compose`, `/compose/:draftId` · 목업 [S05-compose.png](mockups/png/S05-compose.png)

## 1. 목적

Gmail 대체 앱의 기본 작성 기능. 받는 사람·참조·제목·본문·첨부를 쓰고 직접 보낸다. 프로필의 서명이 자동으로 붙는다.

## 2. 진입 · 나가기

- 진입: 사이드바 [새 메일], `Ctrl N`, S03 [답장](RE: 제목·받는 사람·인용문 채움), 임시보관함 항목, S08 [메일로 보내기](보고서 본문 채움).
- 나가기: [보내기] → 직전 화면 + 토스트 "메일을 보냈어요 · 실행 취소(5초)". [삭제] → 확인 대화상자.

## 3. 레이아웃

공통 틀 + 본문 전체를 작성 영역으로. 머리 44(“새 메일” + 오른쪽 저장 상태) / 입력 줄(각 48, 아래 1px 선) / 편집 도구 줄 / 본문 / 하단 버튼 줄.

## 4. 구성 요소

| # | 요소 | 컴포넌트 | 내용 |
| --- | --- | --- | --- |
| 1 | 받는 사람 · 참조 | 받는 사람 칩 + 자동완성 `Popover` | 칩: 아바타 20 + 이름(부서) + ×. 입력하면 "자주 연락하는 사람"(보낸·받은 메일 기준) 목록 |
| 2 | 본문 편집 | 리치 텍스트(굵게·기울임·밑줄·링크·첨부·목록) | 처음에 프로필 첫 인사·마무리를 채우지는 않는다(빈 본문). 서명만 자동 |
| 3 | 서명 · 첨부 | 서명 블록(점선 위, muted 13px) + 첨부 카드 | 첨부 카드: 파일 아이콘 + 이름 + 크기 + × |
| 4 | 하단 버튼 | [보내기] primary · [임시 저장] · [첨부] ghost · 오른쪽 [삭제] ghost | `Ctrl Enter` = 보내기 |

## 5. 동작

- 입력 후 3초마다 자동 임시 저장 → 머리 오른쪽 "임시 저장됨 · 09:41".
- 받는 사람 없이 [보내기] → 받는 사람 칸에 danger 테두리 + "받는 사람을 입력해 주세요".
- 제목 없이 보내기 → 확인 대화상자 "제목 없이 보낼까요?".
- 첨부: 끌어다 놓기 지원, 25MB 초과 시 경고.

## 6. 상태

- 보내는 중: [보내기] 스피너 + 비활성
- 보내기 실패: 상단 띠(danger-subtle) "보내지 못했어요. 임시보관함에 저장했어요 · 다시 보내기"

## 7. 문구

- 머리: "새 메일" / 답장일 때 "답장"
- 자동완성 제목: "자주 연락하는 사람"

## 8. 데이터 · API

`POST /mails/send` · 임시 저장 `POST /drafts/mail`(신규 제안) · 자동완성 `GET /contacts?q=`(신규 제안) · 서명 = `profiles.signature`

## 9. 완료 체크리스트

- [ ] 보낸 메일이 보낸편지함에 나타난다 (문체 학습 대상)
- [ ] 서명이 자동으로 붙고, 프로필을 바꾸면 다음 작성부터 반영
- [ ] 자동 임시 저장 후 앱을 껐다 켜도 임시보관함에 남는다
- [ ] 보내기 전에는 절대 자동 발송되지 않는다
