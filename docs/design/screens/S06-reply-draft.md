# S06. 답장 초안 (F2)

> 기능 F2 · 담당 D · 라우트 `/reply/:mailId` · 목업 [S06-reply-draft.png](mockups/png/S06-reply-draft.png)

## 1. 목적

원본 메일·관련 메일·내 프로필로 '내가 쓴 것처럼' 답장 초안을 만들고, 무엇이 반영됐는지 보여 준 뒤 사용자가 고쳐서 직접 보내게 한다.

> 임시 가정(open-questions #9): 초안은 **별도 답장 화면**에 보여 준다. 고친 초안은 문체 학습에 반영하지 않는다.

## 2. 진입 · 나가기

- 진입: S03·S04 [◆ 답장 초안 만들기], S07 결과의 [◆ 답장 초안], S10 놓친 제안의 [◆ 회신 초안].
- 나가기: [보내기] → S03 + 토스트. 왼쪽 위 [‹ 받은편지함] → 확인 없이 임시 저장 후 S03.

## 3. 레이아웃

공통 틀 + **원본 패널 420**(`gray-25` 바탕) + **작성 영역(나머지)**.
작성 영역: 받는 사람·참조 줄 44 / 제목 줄 44 / 답장 방향 줄 / 초안 본문 / "반영된 것" 박스 / 하단 버튼 줄.

## 4. 구성 요소

| # | 요소 | 컴포넌트 | 내용 |
| --- | --- | --- | --- |
| 1 | 원본 메일 + 요청사항 | 텍스트 + AI 박스 | 원본 제목(title)·보낸 사람·본문 요약. 아래 "◆ 요청사항" ①②③ (F1 `action_items`) |
| 2 | 답장 방향 | `AiChip` 선택형 ×2~3 | AI가 제안한 방향. 선택된 칩 = `ai` 바탕. 오른쪽 caption "문체: 정중 · 길이 보통" |
| 3 | 초안 본문 | 편집 가능한 본문 + `ProfileUnderline` | 프로필이 반영된 부분(인사·마무리·서명·자주 쓰는 표현·참고 메일 인용)에 연보라 밑줄. 사용자가 고치면 그 부분 밑줄은 사라짐 |
| 4 | 이 초안에 반영된 것 | 회색 박스(12px) | "프로필: …" / "참고한 메일: {제목} ({날짜}, 내가 보냄)" — 메일 제목은 링크(ai-text) |
| 5 | 빠른 수정 | `Button` secondary sm | [더 짧게] [더 정중하게] [↻ 다시 쓰기] |
| 6 | 발송 | [임시 저장] secondary · [보내기] primary | 보내기는 항상 사용자가 누름 |

## 5. 동작

- 화면이 열리면 바로 생성 시작 → 방향 칩이 먼저, 본문은 글자가 생기는 대로(스트리밍).
- 방향 칩 변경 → 본문 다시 생성(이전 본문은 흐리게 → 새 본문). 사용자가 이미 고쳤다면 확인 "고친 내용이 사라져요. 다시 만들까요?".
- [더 짧게]/[더 정중하게] → 현재 본문 기준으로 다시 쓰기.
- 참고한 메일 링크 → 오른쪽에서 미리보기 Popover.

## 6. 상태

| 상태 | 표현 |
| --- | --- |
| 생성 중 | 방향 줄: 칩 스켈레톤 3개 / 본문: "◆ 답장 초안을 만들고 있어요…" + 줄 스켈레톤 4줄 |
| 생성 실패 | 본문 자리에 "초안을 만들지 못했어요 · 다시 시도 · 직접 쓰기" (직접 쓰기 = S05 답장 모드) |
| 참고 메일 없음 | "참고한 메일" 줄을 표시하지 않음 |

## 7. 문구

- 방향 머리: "◆ 답장 방향"
- 근거 박스 제목: "이 초안에 반영된 것 (밑줄 친 부분)"

## 8. 데이터 · API

`POST /drafts { mail_id, direction? }` → `{ directions[], body, evidence[] }` (스트리밍) · `POST /drafts/{id}/revise { action }` · `POST /mails/send`
`evidence[]` = `{ span: [시작, 끝], source: "profile.greeting" | "profile.phrase" | "mail:{id}" }` → 밑줄 위치

## 9. 완료 체크리스트

- [ ] 10초 안에 방향 칩과 초안이 나온다 (첫 글자는 3초 안)
- [ ] 밑줄 부분과 "반영된 것" 목록이 서로 맞는다
- [ ] 방향 칩을 바꾸면 초안이 그 방향으로 바뀐다
- [ ] 초안은 자동으로 보내지지 않는다
- [ ] 원본 패널의 요청사항이 F1 분석 결과와 같다
