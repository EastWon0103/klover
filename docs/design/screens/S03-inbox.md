# S03. 받은편지함 (AI 분류) — 기준 화면

> 기능 F0·F1 · 담당 A(틀·목록) · C(AI 표시) · 라우트 `/mail/:box/:mailId?` · 목업 [S03-inbox.png](mockups/png/S03-inbox.png)

**이 화면을 가장 먼저 완성한다.** 나머지 화면은 "S03과 같은 스타일로"를 기준으로 만든다.

## 1. 목적

메일을 열지 않아도 무엇에 관한 메일인지, 내가 할 일이 있는지 알 수 있게 한다. 메일을 열면 AI 요약과 근거 문장을 함께 보여 준다.

## 2. 진입 · 나가기

- 진입: 앱 실행 기본 화면, 사이드바 메일함·스마트 보기·카테고리 클릭(같은 화면, 목록만 필터).
- 나가기: [◆ 답장 초안 만들기] → S06, [답장] → S05(답장 모드), 검색 → S07, 일정 제안이 있는 메일 → 읽기 영역이 S04 형태.

## 3. 레이아웃

공통 틀 + **메일 목록 360** + **읽기 영역(나머지)**.

- 목록: 머리 44(메일함 이름 + 건수 + 정렬) / 날짜 구분 줄(`gray-25` 바탕, 12px 600) / 메일 한 줄 반복
- 읽기: 도구 줄 44 / 본문(패딩 20·28, 최대 폭 760)

## 4. 구성 요소

| # | 요소 | 컴포넌트 | 내용 |
| --- | --- | --- | --- |
| 1 | 스마트 보기 · AI 카테고리 | `Sidebar` 항목 | 회신 필요 / 마감 임박 / 할 일 + 카테고리 7종(색 점). 건수는 `GET /mails/counts` |
| 2 | 메일 한 줄 | `MailListItem` | 보낸 사람(이름 + 부서) · 시간 / 제목 / ◆ 한 줄 요약 / 태그(`CategoryTag` + `StatusTag`). 안 읽음 = 초록 점 + 굵게. 선택 = `selected` + 왼쪽 3px 막대 |
| 3 | AI 요약 박스 | `AiSummaryBox` | "◆ AI 요약" + 요약 1~2줄(핵심어 굵게) + 구분선 + "내가 할 일 / 마감 / 우선순위·이유" |
| 4 | 분류 변경 | `CategorySelect` | "분류 [업무 요청 ▾] 틀렸다면 눌러서 바꿔 주세요. 비슷한 메일에 반영됩니다." 누르면 7종 드롭다운 |
| 5 | 도구 줄 | `Button` | [◆ 답장 초안 만들기] (ai, sm) [답장] (secondary) [보관] [삭제] [할 일 추가] (ghost) … [⋯](스팸, 읽지 않음 표시, 원문 보기) |
| 6 | 자연어 검색창 | 상단 바 | 누르거나 `Ctrl K` → 입력, Enter → S07 |
| 7 | 근거 문장 강조 | `EvidenceHighlight` | AI가 요청·마감·일정을 뽑은 문장. 마우스를 올리면 "AI가 이 문장에서 마감을 찾았어요" 툴팁 |

메일 읽기 머리: 제목(heading) / 아바타 32 + 보낸 사람(굵게) + 부서·주소(muted) / "받는 사람·참조"(caption) / 오른쪽 날짜(caption). 첨부가 있으면 본문 아래 첨부 카드.

## 5. 동작

- 목록 클릭 → 읽기 영역 갱신 + 읽음 처리. `J`/`K` 위아래 이동, `E` 보관, `Del` 삭제, `R` 답장.
- 정렬: 중요도순(기본: priority → 받은 시간) / 시간순.
- 분류 변경 → `PATCH /mails/{id}/category` → 태그·사이드바 건수 즉시 갱신 + 앱 안 토스트 "같은 발신자의 다음 메일부터 '보고·공유'로 분류할게요".
- 보관·삭제 → 목록에서 빠지고 다음 메일 선택 + 토스트 [실행 취소] 5초.
- 새 메일 도착(WebSocket) → 목록 맨 위에 추가(요약 자리는 "◆ AI가 분석하고 있어요…") → `mail.analyzed`에서 요약·태그 채움.
- 목록 스크롤 끝 → 다음 페이지(커서).

## 6. 상태

| 상태 | 표현 |
| --- | --- |
| 목록 불러오는 중 | `MailListItem` 모양 스켈레톤 8줄 |
| 메일 미선택 | 읽기 영역 가운데 caption "메일을 선택하세요" |
| 분석 중 | 목록: 요약 자리 문구 + 태그 스켈레톤 / 읽기: AI 요약 박스 자리 스켈레톤 |
| 분석 실패 | AI 요약 박스 대신 회색 줄 "요약을 만들지 못했어요 · 다시 시도" (원문은 그대로) |
| 필터 결과 0건 | `EmptyState` 작은형: "회신이 필요한 메일이 없어요" 등 |

## 7. 문구

- 목록 머리: "받은편지함 59" · "중요도순 ▾"
- 날짜 구분: "오늘 · 10월 14일 (화)", "어제", "이번 주", "10월 6일 (월)"
- AI 요약 박스 아래 줄: "내가 할 일 {할 일}" "마감 {MM/DD(요일)}" "우선순위 {높음} · {이유}"

## 8. 데이터 · API

- `GET /mails?box=&category=&smart=&sort=&cursor=` · `GET /mails/{id}` · `GET /mails/counts`
- `PATCH /mails/{id}/category` · `POST /mails/{id}/archive` · `DELETE /mails/{id}`
- 화면 필드 ↔ 메타데이터: 한 줄 요약 = `summary` 첫 문장, 태그 = `user_label ?? category` + `needs_reply && !replied` + `action_items[].due`, 우선순위 = `priority` + `priority_reason`, 강조 = `evidence_spans` (mails 테이블에 추가 필요)
- WebSocket: `mail.received`, `mail.analyzed`

## 9. 완료 체크리스트

- [ ] 목업과 나란히 놓고 봤을 때 영역 크기·색·글자가 같다
- [ ] 7개 카테고리 태그 색이 디자인 시스템 표와 같다
- [ ] 안 읽음/읽음/선택/분석 중 4가지 줄 모양이 구분된다
- [ ] 분류 변경이 바로 반영되고 건수가 맞다
- [ ] 키보드만으로 목록 이동·보관·삭제·답장이 된다
- [ ] 1280 × 720 창에서도 깨지지 않는다
