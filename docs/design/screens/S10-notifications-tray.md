# S10. Windows 알림 · 트레이 · 놓친 제안 (F0·F5)

> 기능 F0·F5 · 담당 A(트레이·알림 틀) · C(제안 내용) · 목업 [S10-notifications-tray.png](mockups/png/S10-notifications-tray.png)

앱 창 밖에서 보이는 세 가지를 정의한다. **A. 놓친 제안 대화상자 / B. Windows 알림 / C. 트레이 메뉴**

## A. 놓친 제안 대화상자

- 언제: 앱이 꺼져 있던 동안 생긴 제안이 있을 때, 다음 실행 직후 받은편지함 위에 1회.
- 모양: `Dialog` 폭 560, 모서리 12. 머리 = 마크 22 + "Klover가 꺼져 있던 동안 제안 N건"(title) + caption "{시작} ~ {끝} 도착한 메일".
- 목록 한 줄: 유형 아이콘 32(유형 색 연한 바탕) + 제목(14 700) + caption "{유형} · {핵심 정보} · {보낸 사람}" + 오른쪽 버튼 2개.
  - 일정: [캘린더에 추가] (primary sm) [무시] / 할 일: [할 일에 추가] (secondary sm) [무시] / 회신: [◆ 회신 초안] (ai-outline sm) [무시]
- 하단(`gray-25`): [모두 무시] (ghost) [나중에 보기] (secondary) → 나중에 보기 = 닫고 각 메일의 S04 패널에 남김.
- 최대 5줄, 넘으면 "외 N건 더 보기".

## B. Windows 알림 (토스트)

- 언제: 앱이 켜져 있고(트레이 포함) 알림 설정이 켜진 유형의 제안이 생겼을 때 즉시.
- 구현: Electron `Notification` — Windows 기본 알림 모양을 쓴다(목업은 모양 참고용). 앱 아이콘 = `brand/png/app-icon-256.png`, 앱 이름 "Klover"(AppUserModelID 설정 필수).
- 내용 규칙:

| 줄 | 내용 | 예 |
| --- | --- | --- |
| 제목 | 제안 유형 | 일정 등록 제안 / 할 일 제안 / 회신이 필요해요 / 결재 요청 / 중요 메일 |
| 본문 1 | 보낸 사람: 메일 제목(또는 일정 제목) | 이수진 팀장: 3분기 결산 리뷰 회의 |
| 본문 2 | 핵심 정보 | 10/16(금) 14:00, 본사 7층 대회의실 |
| 경고(선택) | 겹침·마감 임박 | ⚠ '팀 주간회의'와 시간이 겹칩니다 |
| 버튼 | 최대 2개 | [캘린더에 추가] [메일 열기] |

- 버튼 동작: [캘린더에 추가] → 바로 등록(임시 가정 open-questions #12: 허용) + 완료 알림 "캘린더에 추가했어요". [메일 열기] / 알림 본문 클릭 → 창을 앞으로 + S04.
- 같은 메일의 제안이 여러 개면 알림은 1개(가장 중요한 제안), 나머지는 S04에서.
- 1분 안에 3개 넘게 오면 묶음 알림 "새 제안 N건 · Klover에서 보기".

## C. 트레이 아이콘 · 메뉴

- 아이콘: 작업 표시줄이 어두우면 `brand/png/tray-light-32.png`(흰색), 밝으면 `tray-dark-32.png`. 안 본 제안이 있으면 오른쪽 위 보라 점(별도 아이콘 파일 `tray-*-badge` 추가 예정).
- 툴팁: "Klover · 새 제안 N건"
- 왼쪽 클릭: 창 열기/앞으로. 오른쪽 클릭: 메뉴(폭 220, 항목 34, 구분선).

| 메뉴 | 동작 |
| --- | --- |
| Klover 열기 | 창 표시 |
| 새 메일 | 창 표시 + S05 |
| 알림 일시 중지 (1시간) | 1시간 알림 끔, 메뉴 글자가 "알림 다시 켜기"로 |
| 설정 | 창 표시 + S09 |
| 종료 | 앱 완전 종료 (알림·분석 알림 중단 안내 없이 바로) |

- 창 닫기(×) 첫 회에만 앱 안 안내 "Klover는 트레이에서 계속 실행돼요. 완전히 끄려면 트레이 아이콘에서 '종료'를 누르세요."

## 데이터 · API

WebSocket `suggestion.created` → main 프로세스가 알림 표시 · `GET /suggestions?status=pending&notified=false`(놓친 제안) · `POST /suggestions/{id}/approve|dismiss`

## 완료 체크리스트

- [ ] 창을 닫아도 트레이에 남고, 트레이 '종료'로만 끝난다
- [ ] 앱 실행 중 새 일정 메일 → 30초 안에 Windows 알림
- [ ] 알림 버튼과 본문 클릭이 정의대로 동작
- [ ] 앱이 꺼져 있던 동안의 제안이 다음 실행 때 대화상자로 나온다
- [ ] 설정에서 끈 유형은 알림이 오지 않는다
- [ ] Windows 알림 센터에 앱 이름이 "Klover"와 Klover 아이콘으로 표시된다
