# S08. 주간 보고 (F4)

> 기능 F4 · 담당 D(서버) · A(화면) · 라우트 `/report/weekly` · 목업 [S08-weekly-report.png](mockups/png/S08-weekly-report.png)

## 1. 목적

기간을 고르면 한 주의 메일을 업무 단위로 묶어 내 양식의 보고서를 만들고, 항목마다 근거 메일을 확인하게 한다.

## 2. 진입 · 나가기

- 진입: 사이드바 '도구 > 주간 보고'. 사용 1주 전이면 빈 상태 "사용 1주 후부터 만들 수 있어요 (N일 남음)".
- 나가기: [메일로 보내기] → S05(받는 사람·제목·본문 채움).

## 3. 레이아웃

공통 틀 + 본문: 선택 줄(패딩 14·24, 아래 선) / **보고서 영역(나머지, 패딩 22·32)** + **근거 패널 300**(`gray-25`) / 하단 버튼 줄.

## 4. 구성 요소

| # | 요소 | 컴포넌트 | 내용 |
| --- | --- | --- | --- |
| 1 | 기간 · 양식 · 보고 대상 | `Select` ×3 (라벨 caption) | 기본값 = 지난주, 프로필 양식, 프로필 보고 대상 |
| 2 | 보고서 제목 · 부제 | heading + caption | "{팀} 주간 업무 보고 ({기간})" / "{이름 직급} · 작성 {날짜} · {공휴일} 휴무 반영 · ◆ AI 작성 — 내용을 바로 고칠 수 있어요" |
| 3 | 섹션 · 항목 | 섹션 제목(15 700, 아래 선) + 항목 줄 + `EvidenceBadge` | 항목은 바로 편집 가능(클릭 시 입력). 선택된 항목 = `ai-subtle` 바탕 + 테두리, 배지 채움 |
| 4 | 다시 만들기 | `Button` ai | 고친 내용이 있으면 확인 대화상자 |
| 5 | 근거 메일 · 포함 범위 | 목록 + 숫자 표 | 위: 선택한 항목의 근거 메일(제목 굵게, "보낸 사람 → 받는 사람 · 날짜"). 아래: 기간 내 / 업무로 묶인(N개 업무) / 제외 + "제외된 메일 보기 ›" |
| 6 | 내보내기 · 보내기 | [복사] [Word로 내보내기] secondary · [{보고 대상}에게 메일로 보내기] primary | — |

## 5. 동작

- 화면을 열면 기본 기간으로 바로 생성(지난번 결과가 같은 기간이면 저장본 표시).
- 항목 클릭 → 오른쪽 근거 메일 갱신. 근거 메일 클릭 → 메일 미리보기 Popover.
- 항목 편집: 클릭 → 한 줄 입력 → Enter 저장. 항목 추가는 섹션 끝 "+ 항목 추가"(hover 시).
- [Word로 내보내기] → .docx 저장 대화상자. [복사] → 개조식 텍스트로 클립보드 + 토스트.
- "제외된 메일 보기" → 대화상자에 목록, 메일을 체크해 [보고에 포함] 가능.

## 6. 상태

| 상태 | 표현 |
| --- | --- |
| 생성 중 | 섹션 제목 4개는 바로, 항목 자리 스켈레톤 + "◆ 한 주의 메일 86건을 정리하고 있어요…" |
| 기간 내 메일 없음 | `EmptyState`: "이 기간에 주고받은 업무 메일이 없어요" |
| 사용 1주 전 | `EmptyState`: "사용 1주 후부터 만들 수 있어요 (N일 남음)" |

## 7. 문구

섹션 이름은 프로필 양식 그대로(기본: 1. 금주 주요 업무 / 2. 진행 중인 업무 / 3. 이슈·요청사항 / 4. 차주 계획). 근거 배지 "근거 N".

## 8. 데이터 · API

`POST /reports/weekly` · `GET /reports/weekly/{id}/excluded` · `POST /reports/weekly/{id}/export?format=docx` · 편집 저장 `PATCH /reports/weekly/{id}`(신규 제안)

## 9. 완료 체크리스트

- [ ] 모든 항목에 근거 배지가 있고, 누르면 근거 메일이 바뀐다
- [ ] 포함 범위 숫자가 맞다 (전체 = 묶인 + 제외)
- [ ] 고친 내용이 복사·Word·메일에 그대로 들어간다
- [ ] 메일로 보내기는 작성 화면을 채워 열 뿐 자동 발송하지 않는다
