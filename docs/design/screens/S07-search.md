# S07. 자연어 검색 (F3)

> 기능 F3 · 담당 D · 라우트 `/search?q=` · 목업 [S07-search.png](mockups/png/S07-search.png)

## 1. 목적

말하듯 입력한 문장을 AI가 어떻게 이해했는지 먼저 보여 주고, 그 조건으로 찾은 메일과 출처가 붙은 요약 답변을 함께 보여 준다.

> 임시 가정(open-questions #10): 검색은 **별도 화면**(목록+읽기 영역 자리). 결과에서 답장 초안으로 바로 이어진다.

## 2. 진입 · 나가기

- 진입: 상단 검색창 Enter, `Ctrl K` 후 Enter, 최근 검색 클릭.
- 나가기: 결과 카드 클릭 → S03(해당 메일 선택), [◆ 답장 초안] → S06, [‹ 받은편지함으로] 또는 `Esc` → S03.

## 3. 레이아웃

공통 틀(검색창은 입력 상태: `ai` 테두리 + 연보라 링) + 본문.
본문: "이렇게 이해했어요" 줄(패딩 14·24, 아래 1px 선) / 결과 영역(패딩 18·24, 요소 사이 12) + **필터 패널 260**(`gray-25`).

## 4. 구성 요소

| # | 요소 | 컴포넌트 | 내용 |
| --- | --- | --- | --- |
| 1 | 검색창 | 상단 바 | 입력한 문장 그대로 유지, 고쳐서 다시 Enter 가능 |
| 2 | 이렇게 이해했어요 | `AiChip` (×) + 추가 칩 | 키(기간·상대·주제·상태·대상) + 값 + ×. "+ 조건 추가"는 점선 칩 → 키 선택 Popover |
| 3 | AI 답변 | `AiSummaryBox` 변형 | "◆ AI 답변" + 2~3문장, 문장 끝 `CitationBadge` |
| 4 | 결과 카드 | `ResultCard` | 번호 배지(답변의 출처 번호와 같음) · 보낸 사람(부서) · 날짜 / 제목 / 인용(일치 단어 강조) / 태그 + 미회신 N일 + 맞는 이유(caption) / [◆ 답장 초안] |
| 5 | 일부 만족 · 이어서 질문 | 접힘 줄 + 비활성 입력 | "조건을 일부만 만족하는 메일 N건 더 보기 ▾" / "◆ 이어서 질문하기…" 점선 입력 + `2차` 배지(누를 수 없음) |
| 6 | 필터 패널 | `Input`·`CategoryTag`·`Segmented` | 기간(직접 수정), 카테고리, 첨부파일(전체/있음), 최근 검색 3개 |

## 5. 동작

- Enter → 1) 해석 칩 먼저 표시 → 2) 결과 목록 → 3) AI 답변(스트리밍). 세 단계가 차례로 채워진다.
- 칩 × 또는 필터 변경 → 해석은 그대로 두고 `overrides`로 다시 검색.
- 출처 번호 클릭 → 해당 결과 카드로 스크롤 + 1초 강조.
- 정렬: 관련도순(기본) / 최신순.

## 6. 상태

| 상태 | 표현 |
| --- | --- |
| 해석 중 | 칩 자리 스켈레톤 3개 + "◆ 질문을 이해하고 있어요…" |
| 검색 중 | 결과 카드 스켈레톤 3개 |
| 결과 0건 | AI 답변 자리: "조건에 맞는 메일을 찾지 못했어요." + 제안 "기간을 넓혀 볼까요? [최근 3개월]" |
| 메일이 아직 적음 | 맨 위 띠(muted): "메일이 쌓일수록 검색이 정확해져요 (현재 N건)" |

## 7. 문구

- "이렇게 이해했어요" · "조건에 맞는 메일 N건" · "관련도순 ▾" · "조건을 일부만 만족하는 메일 N건 더 보기 ▾"
- 맞는 이유 예: "'예산 재배정'이 주제와 일치", "'출장비 초과'가 예산 주제와 의미상 가까움"

## 8. 데이터 · API

`POST /search { query, overrides? }` → `{ parsed: {filters, topic, expansions}, results[{mail_id, score, reason, snippet, match_terms}], partial[], answer{text, citations[]} }` · `GET /search/recent`

## 9. 완료 체크리스트

- [ ] 칩·결과·답변이 이 순서로 나타난다
- [ ] 출처 번호와 결과 카드 번호가 일치한다
- [ ] 칩을 지우면 그 조건 없이 다시 검색된다
- [ ] 결과 0건일 때 빈 화면 대신 안내와 다음 행동이 보인다
- [ ] '이어서 질문하기'는 보이지만 동작하지 않는다(2차)
