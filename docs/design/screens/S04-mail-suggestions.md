# S04. 메일 읽기 + AI 제안 (F5)

> 기능 F5 · 담당 C · 라우트 `/mail/:box/:mailId` (제안이 있는 메일) · 목업 [S04-mail-suggestions.png](mockups/png/S04-mail-suggestions.png)

## 1. 목적

메일 속 일정·할 일·회신 요청을 AI가 채운 **제안 카드**로 정리하고, 사용자가 확인·수정한 뒤 직접 실행하게 한다.

## 2. 진입 · 나가기

- 진입: S03에서 `◆ 일정 제안` 태그가 있는 메일 선택, Windows 알림의 [메일 열기] (S10-B), 놓친 제안 대화상자(S10-A).
- 나가기: [◆ 회신 초안 만들기] → S06.

## 3. 레이아웃

S03과 같은 틀. 읽기 영역을 **본문(나머지) + 제안 패널 340**으로 나눈다. 제안 패널은 `gray-25` 바탕, 왼쪽 1px 선, 패딩 16, 카드 사이 12.
1280px 이하 창에서는 제안 패널을 본문 위(AI 요약 박스 자리)로 옮긴다.

## 4. 구성 요소

| # | 요소 | 컴포넌트 | 내용 |
| --- | --- | --- | --- |
| 1 | 메일 머리 + 태그 | S03과 같음 | 태그 줄에 `◆ 일정 제안` |
| 2 | 일정 등록 카드 | `SuggestionCard` (강조형) | 머리 "📅 일정 등록"(회의·일정 초록). 제목·일시·장소·캘린더를 입력창으로(수정 가능). 캘린더는 Google 캘린더 목록 Select |
| 3 | 겹침 경고 + 버튼 | `ConflictWarning` + `Button` | "같은 시간에 '팀 주간회의'(14:00–15:00)가 있습니다" / [캘린더에 추가] (primary, 넓게) [무시] (secondary) |
| 4 | 할 일 · 회신 카드 | `SuggestionCard` | 할 일: 제목 + "마감 10/15(목) · 마감 전날 알림" + [+ 할 일에 추가] / 회신: 설명 + [◆ 회신 초안 만들기] (ai-outline) |
| 5 | 근거 문장 강조 | `EvidenceHighlight` | 일시·장소·할 일을 뽑은 문장. 카드에 마우스를 올리면 해당 문장이 진해진다 |

패널 머리: "◆ AI 제안 N건" (ai-text 700) + 오른쪽 caption "제안만 하고, 실행은 직접 고릅니다".
카드 순서: 일정 → 할 일 → 회신 → 결재 → 중요 발신자. 가장 위 카드만 강조형.

## 5. 동작

- [캘린더에 추가] → `POST /suggestions/{id}/approve` (수정한 값 포함) → 카드가 "✓ 캘린더에 추가했어요 · Google Calendar에서 보기"로 바뀜.
- [무시] → `POST /suggestions/{id}/dismiss` → 카드가 접히며 "무시함 · 되돌리기" 한 줄.
- [할 일에 추가] → 할 일 생성, 사이드바 '할 일' 건수 +1.
- [◆ 회신 초안 만들기] → S06, 답장 방향 기본값 "참석 여부 회신".
- 모든 제안 처리 후 패널은 "처리한 제안 3건" 요약만 남기고 접힌다(다시 펼치기 가능).

## 6. 상태

- 제안 생성 중: 카드 자리 스켈레톤 1개 + "◆ 일정을 확인하고 있어요…"
- 캘린더 등록 실패: 카드 아래 danger "캘린더에 추가하지 못했어요. 연결 상태를 확인해 주세요 · 다시 시도"
- 캘린더 미연결: [캘린더에 추가] 대신 [캘린더 연결하기] → S09 캘린더 연결

## 7. 문구

- 패널 머리: "◆ AI 제안 3건" / "제안만 하고, 실행은 직접 고릅니다"
- 겹침: "같은 시간에 '{일정 이름}'({시작}–{끝})가 있습니다"
- 할 일 설명: "마감 {MM/DD(요일)} · 마감 전날 알림"

## 8. 데이터 · API

`GET /suggestions?mail_id=` · `POST /suggestions/{id}/approve` · `POST /suggestions/{id}/dismiss` · `POST /todos` · 제안 `payload.conflicts[]`

## 9. 완료 체크리스트

- [ ] 제안이 없는 메일은 S03 모양(패널 없음)
- [ ] 일정 카드의 값을 고친 뒤 등록하면 고친 값으로 등록된다
- [ ] 겹치는 일정이 있을 때만 경고가 보인다
- [ ] 어떤 버튼도 누르기 전에는 아무것도 실행되지 않는다
- [ ] 카드에 마우스를 올리면 본문 근거 문장이 함께 강조된다
