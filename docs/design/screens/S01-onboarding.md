# S01. 첫 실행 설정 (5단계)

> 기능 F0 · 담당 A · 라우트 `/onboarding/:step` (1~5) · 목업 [S01-onboarding.png](mockups/png/S01-onboarding.png) (4단계 모습)

## 1. 목적

처음 실행한 사용자가 5단계로 Gmail 연결, 프로필, 문체 학습 동의, 알림 설정을 마치고 받은편지함(S02)으로 들어가게 한다.

## 2. 진입 · 나가기

- 진입: 설정을 끝내지 않은 상태로 앱 실행 시 자동. 중간에 껐다면 마지막 단계부터 이어서.
- 나가기: 5단계 [Klover 시작하기] → S02. 창 닫기(×) = 앱 종료(설정 전에는 트레이로 숨기지 않음).

## 3. 레이아웃

- 별도 창 1040 × 680, 화면 가운데. 크기 조절 불가, 최대화 버튼 없음.
- 왼쪽 단계 패널 280 (`muted` 바탕) / 오른쪽 내용 영역 (패딩 32·40) / 하단 버튼 줄(위 1px 선).

## 4. 구성 요소

| # | 요소 | 컴포넌트 | 내용 |
| --- | --- | --- | --- |
| 1 | 로고 + 단계 목록 | `WizardSteps` | 로고 높이 28. 단계: Gmail 계정 연결 / 프로필 입력 / 문체 학습 동의 / 알림과 시작 프로그램 / 완료. 완료 단계는 아래에 입력값 요약(예: hong.gildong@gmail.com) |
| 2 | 동의 내용 요약 | 텍스트 | 3단계를 지난 뒤 왼쪽 아래에 고정 표시 |
| 3 | 설정 카드 | 카드 + `Switch` | 제목 + 설명 + 오른쪽 스위치. 카드 모서리 10, 패딩 14·16 |
| 4 | 알림 유형 선택 | `Checkbox` ×5 | 일정 등록 / 할 일 / 회신 필요 / 결재·승인 / 중요 발신자. 'AI 제안 즉시 알림'을 끄면 비활성 |
| 5 | 이전 · 다음 | `Button` secondary · primary | 1단계에는 [이전] 없음. 5단계는 [Klover 시작하기] |

### 단계별 내용 영역

| 단계 | 제목 | 내용 | [다음] 활성 조건 |
| --- | --- | --- | --- |
| 1 | Gmail 계정 연결 | 설명 + [Google 계정으로 연결] (흰 버튼, Google 로고 자리). 연결 후 계정 이메일 + "✓ 연결됨" 배지. 같은 화면에 Google Calendar 권한도 함께 안내 | 연결 완료 |
| 2 | 프로필 입력 | 이름·직급·소속·담당 업무 입력 + 첫 인사·마무리 미리 채움(“안녕하세요, {소속} {이름}입니다.”). S09 기본 정보·문체와 같은 필드 | 이름·소속 입력 |
| 3 | 문체 학습 동의 | 안내문 + 학습하는 것/하지 않는 것 목록 + [동의하고 계속] / [나중에 하기] | 항상 |
| 4 | 알림과 시작 프로그램 | 목업 그대로: 자동 실행, 트레이 실행, 즉시 알림(+유형), 캘린더 연결 상태 | 항상 |
| 5 | 완료 | 마크 64 + "준비가 끝났어요" + 기능 준비 상태 요약(S02와 같은 목록) + [Klover 시작하기] | — |

## 5. 동작

- [Google 계정으로 연결] → 기본 브라우저로 OAuth 열기 → 돌아오면 서버에 코드 전달 → 성공 시 이메일 표시.
- 스위치·체크박스는 바로 로컬 상태에 저장, [다음]을 누를 때 서버로 저장.
- '자동 실행' 켬 → Electron `app.setLoginItemSettings({ openAtLogin: true })`.

## 6. 상태

- 연결 중: [Google 계정으로 연결] 버튼이 스피너 + "브라우저에서 로그인해 주세요"
- 연결 실패: 버튼 아래 danger 글자 "연결하지 못했어요. 다시 시도해 주세요."
- 저장 중: [다음] 버튼 비활성 + 스피너

## 7. 문구

- 4단계 설명: "메일이 도착하는 즉시 AI 제안을 받으려면 Klover가 켜져 있어야 합니다."
- 하단 안내: "Klover가 꺼져 있던 동안 생긴 제안은 다음 실행 때 모아서 보여 드립니다."
- 3단계 동의문: "Klover에서 보낸 메일의 표현과 문장 습관을 분석해 답장 초안에 반영합니다. 설정에서 언제든 끄고 학습 기록을 삭제할 수 있습니다."

## 8. 데이터 · API

`POST /auth/google` · `PUT /profile` · `PUT /settings/notifications` · 로컬: `onboardingStep`, `onboardingDone`

## 9. 완료 체크리스트

- [ ] 단계 표시가 완료/현재/대기 3가지 모양으로 바뀐다
- [ ] 1단계 연결 전에는 [다음]이 비활성
- [ ] 앱을 껐다 켜면 마지막 단계에서 다시 시작
- [ ] 5단계 완료 후 S02로 이동하고, 다시 실행해도 S01이 나오지 않는다
- [ ] 목업과 비교해 간격·색·글자 크기가 같다
